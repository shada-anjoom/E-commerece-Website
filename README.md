E-commerce Website

About the Project

A web-based e-commerce application developed to provide an online shopping experience. It allows users to browse products and place orders.

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

Features

- User-friendly interface
- Product listing
- Product details
- Order management
- Database integration
- Admin dashboard

Tools Used

- Visual Studio Code
- MongoDB Atlas

How to Run

1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Install the required dependencies using "npm install".
4. Configure the MongoDB connection.
5. Start the server using "npm start" (if configured).
6. Open the application in your browser.
